# Portafolio Personal — Daniel Barragán

Sitio de portafolio personal construido como proyecto de certificación de **Diseño Web Responsivo** (freeCodeCamp). Presenta mi perfil como desarrollador Front-End Junior, mis habilidades técnicas y los proyectos que he desarrollado durante la certificación.

🔗 **Demo en vivo:** https://danielbarragan8905.github.io/PORTAFOLIO-PERSONAL/

## Descripción

El sitio está construido como una sola página (single page) con navegación fija y desplazamiento suave entre secciones:

- **Inicio** — presentación personal y resumen profesional.
- **Perfil** — historia de cambio de carrera, del área administrativa al desarrollo web.
- **Habilidades** — tecnologías y herramientas técnicas, además de habilidades transferibles del área administrativa.
- **Proyectos** — galería de los proyectos publicados en GitHub Pages, cada uno con enlace a su demo en vivo.
- **Contacto** — correo, teléfono y enlace al perfil de GitHub.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, CSS Grid, media queries)
- Diseño responsivo (mobile-first)
- SVG en línea para elementos ilustrativos

## Características técnicas

- Navegación fija (`navbar`) con enlaces de anclaje a cada sección.
- Diseño adaptable a dispositivos móviles, tablet y escritorio.
- Estilos de foco visibles para accesibilidad por teclado.
- Respeta la preferencia de movimiento reducido (`prefers-reduced-motion`).
- Sin frameworks ni librerías externas — HTML y CSS puros.

## Instalación local

Para verlo en tu máquina local, clona el repositorio y abre `index.html` directamente en el navegador:

```bash
git clone https://github.com/danielbarragan8905/PORTAFOLIO-PERSONAL.git
cd PORTAFOLIO-PERSONAL
```

No requiere instalación de dependencias.
